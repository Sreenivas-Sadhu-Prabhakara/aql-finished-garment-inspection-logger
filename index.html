How it works

Acceptance sampling is a three-step lookup, and the whole job is doing it in the right order. First, the lot size and the inspection level give a sample size code letter from Table I of ANSI/ASQ Z1.4 — a lot of 1,000 pieces at General II is code letter J. Second, the code letter gives the sample size: J means draw 80 pieces. Third, the sample size row and the AQL column give the acceptance number Ac and the rejection number Re: at AQL 2.5 that row reads Ac 5 / Re 6. Find 5 majors or fewer and the lot is accepted; find 6 and it is rejected. There is no arithmetic and no rounding anywhere in that chain — a defect count is compared against a number printed in the table.

Each defect class is judged on its own AQL against the same sample, so a lot can pass on minors and fail on majors. Critical defects are normally run at zero tolerance, which is the buyer's clause rather than a Z1.4 column, so a single critical defect rejects the lot.

The arrows are where this goes wrong by hand. Many cells of Table II-A print an arrow instead of a plan, and the arrow has to be followed: ↓ means use the first plan below it and ↑ means use the first plan above it — which changes the code letter and therefore the sample size as well as the accept number. Crucially, the arrows are not only at the edges of the table. The zero-acceptance plans sit three diagonal steps away from the Ac 1 plans rather than one, so every AQL column has an up arrow and a down arrow stranded in the middle of it, directly beneath its Ac 0 / Re 1 entry. At AQL 2.5 that entry is code letter C, 5 pieces: D below it points back up to C, and E below that points down to F — 20 pieces, Ac 1 / Re 2. Read the column as a plain ladder and you will take a 13-piece sample with a zero accept number that the standard never prints. The note under Table II-A also covers small lots: “If sample size equals, or exceeds, lot or batch size, do 100 percent inspection.”

Tables, levels and AQL values implemented

Standard. ANSI/ASQ Z1.4, Sampling Procedures and Tables for Inspection by Attributes (the civilian successor to MIL-STD-105E), harmonised with ISO 2859-1. Table I gives the sample size code letters; Table II-A gives the single sampling plans for normal inspection.

Inspection levels implemented: all seven columns of Table I — S-1, S-2, S-3, S-4, General I, General II and General III. General II is the default and is what most buyers mean when their clause says nothing.

AQL values implemented: 0.065, 0.10, 0.15, 0.25, 0.40, 0.65, 1.0, 1.5, 2.5, 4.0, 6.5, 10 and 15 per cent nonconforming, plus a zero-tolerance setting for critical defects. The Table II-A columns below 0.065 and above 15 are not implemented; pick an implemented column or read those from the printed standard.

Not implemented: tightened inspection (Table II-B), reduced inspection (Table II-C) and the switching rules between normal, tightened and reduced; double and multiple sampling plans (Tables III and IV); limiting quality and AOQL tables. This tool always applies normal, single sampling. If your buyer has switched you to tightened inspection, these numbers do not apply.

Lot size bands (Table I rows): 2–8, 9–15, 16–25, 26–50, 51–90, 91–150, 151–280, 281–500, 501–1,200, 1,201–3,200, 3,201–10,000, 10,001–35,000, 35,001–150,000, 150,001–500,000, 500,001 and over.

Sample sizes by code letter: A 2, B 3, C 5, D 8, E 13, F 20, G 32, H 50, J 80, K 125, L 200, M 315, N 500, P 800, Q 1,250, R 2,000. The letters I and O are not used.

Acceptance numbers: across the AQL columns implemented here the only acceptance numbers in Table II-A are 0, 1, 2, 3, 5, 7, 10, 14 and 21, and the rejection number is always one more than the acceptance number. The full table also uses 30 and 44 in the very high AQL columns, which are outside this tool.

Where the zero-acceptance plans sit, by AQL column: 0.065 → L (200), 0.10 → K (125), 0.15 → J (80), 0.25 → H (50), 0.40 → G (32), 0.65 → F (20), 1.0 → E (13), 1.5 → D (8), 2.5 → C (5), 4.0 → B (3), 6.5 → A (2). The AQL 10 and AQL 15 columns have no zero-acceptance plan at all.

Code letters at General II, lowest lot band to highest: A, B, C, D, E, F, G, H, J, K, L, M, N, P, Q. General I: A, A, B, C, C, D, E, F, G, H, J, K, L, M, N. General III: B, C, D, E, F, G, H, J, K, L, M, N, P, Q, R.

Where two classes end up with different sample sizes. An arrow is followed per AQL column, so a major AQL and a minor AQL can resolve to different code letters and therefore different sample sizes. The tool shows the sample size for each class and asks you to draw the largest of them; each class is then judged against its own plan.

Logged inspections are kept in this browser's local storage on this device only. Nothing is uploaded anywhere, and clearing your browser data clears the log.

An AQL plan is a sampling decision, not a measurement of the whole lot: a lot that passes still contains defects, and a lot that fails may be reworked and re-offered. Your buyer's own AQL clause governs — the inspection level, the AQL per defect class, the defect classification and any switching to tightened inspection are theirs to set, and where this tool and the signed clause disagree, the clause wins. Check the numbers against the printed table or the standard itself before signing a report.
